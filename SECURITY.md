# 🔒 Security Policy

## Reporting a Vulnerability

Please do not disclose security vulnerabilities through public GitHub issues.

Report security issues privately to the repository maintainer.

## Scope

This project is a reference implementation and should not be considered production-ready without additional security hardening.

Production deployments should implement:

- MFA
- OAuth/OIDC
- SSO
- secure secret management
- encryption
- WAF
- rate limiting
- dependency scanning
- security monitoring
- backups
- disaster recovery
