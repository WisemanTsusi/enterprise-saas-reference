# 📜 Auditability

Security-sensitive and administrative actions generate audit events.

Examples:

- LOGIN
- ACCESS_DENIED
- USER_CREATED
- ROLE_CHANGED
- ORGANIZATION_UPDATED
- WORKSPACE_CREATED
- SUBSCRIPTION_CHANGED

Audit events should be treated as append-oriented records.

They provide:

- accountability
- troubleshooting
- security investigation
- compliance evidence
- operational visibility
